# Система учёта экзаменационных ведомостей колледжа

Веб-приложение для хранения факультетов, специальностей, групп, студентов, дисциплин,
экзаменационных ведомостей и оценок, с историей успеваемости и печатью ведомостей в PDF.

**Стек:** Node.js, Express, SQLite, PDFKit · HTML5, CSS3, JavaScript (ES6).

## Запуск

```bash
npm install
npm start        # или npm run dev (с автоперезапуском)
```

Открыть в браузере: <http://localhost:3000> — сервер раздаёт и API, и страницы из `client/`.

При первом запуске создаётся `server/database/vedomosti.db` со всеми таблицами и
демонстрационными данными (5 групп, 40 студентов, ведомости за 2023–2026 гг.).
Чтобы начать с чистыми демо-данными, удалите этот файл и перезапустите сервер.

Отделения, специальности и дисциплины задаются массивом `REFERENCE` в `server/db.js`.
При каждом запуске сервера справочник синхронизируется с базой: новое добавляется,
изменённое обновляется, группы, студенты и оценки не затрагиваются.

Название колледжа для PDF задаётся константой `COLLEGE_NAME` в `server/routes/reportRoutes.js`.

## Структура

```
client/                 страницы и стили
  index.html            главная: дашборд, поиск студентов, последние ведомости
  groups.html           группы: поиск, добавление, редактирование, удаление
  students.html         студенты группы (CRUD, поиск) и ведомости группы
  student.html          карточка студента: история Год → Сессия → Предмет — Оценка
  vedomost.html         без ?id — список и создание ведомостей; с ?id — оценки, статистика, PDF
  js/api.js             запросы к API и общие функции интерфейса
server/
  app.js                Express-приложение
  db.js                 подключение к SQLite, схема таблиц KI_DA_*, демо-данные
  routes/
    facultyRoutes.js    справочники (факультеты, специальности, дисциплины, годы, сессии), дашборд
    groupRoutes.js      /api/groups
    studentRoutes.js    /api/students
    gradeRoutes.js      /api/vedomosti — ведомости, оценки и статистика
    reportRoutes.js     /api/reports/vedomost/:id — PDF
reports/                копии сформированных PDF-ведомостей
```

## API

| Метод          | Путь                                                                 | Назначение                                                      |
| -------------- | -------------------------------------------------------------------- | --------------------------------------------------------------- |
| GET            | `/api/dashboard`                                                     | количество групп, студентов, ведомостей, средний балл           |
| GET            | `/api/faculties`, `/api/specialities`, `/api/years`, `/api/sessions` | справочники                                                     |
| GET            | `/api/subjects?group=ID`                                             | дисциплины специальности группы                                 |
| GET/POST       | `/api/groups?q=`                                                     | список (поиск) / создание группы                                |
| GET/PUT/DELETE | `/api/groups/:id`                                                    | группа                                                          |
| GET            | `/api/students?q=`                                                   | поиск студентов по ФИО по всему колледжу                        |
| GET            | `/api/students/group/:id?q=`                                         | студенты группы                                                 |
| POST           | `/api/students`                                                      | добавить студента                                               |
| GET/PUT/DELETE | `/api/students/:id`                                                  | студент                                                         |
| GET            | `/api/students/:id/history`                                          | история оценок, сгруппированная по годам и сессиям              |
| GET/POST       | `/api/vedomosti?group=`                                              | список / создание (существующая возвращается, а не дублируется) |
| GET/DELETE     | `/api/vedomosti/:id`                                                 | ведомость с оценками и статистикой                              |
| PUT            | `/api/vedomosti/:id/grades`                                          | сохранить оценки `{ grades: [{ student_id, grade }] }`          |
| GET            | `/api/reports/vedomost/:id`                                          | скачать PDF                                                     |

## Оценки и статистика

Допустимые оценки: `5`, `4`, `3`, `2`, `н/я` (неявка); пустое значение — оценка ещё не выставлена.

- Абсолютная успеваемость = (5 + 4 + 3) / всего студентов × 100%
- Качественная успеваемость = (5 + 4) / всего студентов × 100%
- Средний балл считается по выставленным оценкам 2–5, без неявок.
